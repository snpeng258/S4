## S4的输出内容

### 1. 主要输出类型

S4可以输出以下物理量：

#### a) **功率流（Poynting Flux）**
```lua
forward, backward = S:GetPoyntingFlux('LayerName', z_offset)
-- 或
forward_r, backward_r, forward_i, backward_i = S:GetPoyntingFlux('LayerName', z_offset)
```

**物理意义**：
- `forward`: 前向传播的功率流（沿+z方向）
- `backward`: 后向传播的功率流（沿-z方向）
- 单位：归一化功率（相对于入射功率）

#### b) **按衍射级次分解的功率流**
```lua
P = S:GetPoyntingFluxByOrder('LayerName', z_offset)
-- P[i] 包含第i个衍射级次的功率信息
```

**输出格式**：每个衍射级次包含4个值：
- `P[i][1]`: 前向功率（实部）
- `P[i][2]`: 后向功率（实部）
- `P[i][3]`: 前向功率（虚部）
- `P[i][4]`: 后向功率（虚部）

#### c) **衍射级次索引**
```lua
i = S:GetDiffractionOrder(m, n)
-- m, n: 倒格矢坐标（整数）
-- 返回该衍射级次在G矢量列表中的索引
```

#### d) **模式振幅**
```lua
forw, back = S:GetAmplitudes('LayerName', z_offset)
-- 返回前向和后向传播的模式振幅
```

### 2. 衍射级次和角度

**衍射级次**由G矢量定义：
- G矢量 = m·b₁ + n·b₂，其中m、n是整数
- 每个G矢量对应一个衍射级次
- 在均匀层中，衍射级次有明确的物理意义

**角度计算**：
对于第(m,n)个衍射级次，其波矢为：
```
k_x = k_inc_x + G_x = k_inc_x + m·b₁x + n·b₂x
k_y = k_inc_y + G_y = k_inc_y + m·b₁y + n·b₂y
k_z = sqrt(ω²ε - k_x² - k_y²)  （传播模式）
```

**衍射角**：
```
θ = arcsin(sqrt(k_x² + k_y²) / (ω√ε))
φ = arctan(k_y / k_x)
```

## 物理推导：从麦克斯韦方程到RCWA

### 1. 麦克斯韦方程组

在频域（时间依赖 e^(-iωt)）：
```
∇ × E = iωμ₀H
∇ × H = -iωε₀εE
```

对于分层结构，假设：
- 介电常数在xy平面内周期性变化：ε(x,y)
- 结构沿z方向分层
- 入射波矢：k = (k_x, k_y, k_z)

### 2. 傅里叶展开

**介电常数展开**：
```
ε(x,y) = Σ_G ε_G exp(iG·r)
```
其中G是倒格矢，ε_G是傅里叶系数。

**场展开**：
```
E(x,y,z) = Σ_G E_G(z) exp(i(k+G)·r_xy)
H(x,y,z) = Σ_G H_G(z) exp(i(k+G)·r_xy)
```

### 3. 模式分解

对于每一层，求解特征值问题得到**传播模式**：

**特征值方程**（从麦克斯韦方程推导）：
```
[K]² E = ω²ε E
```

其中：
- `K`是k-平行矩阵（包含k_x+G_x, k_y+G_y）
- `ε`是介电常数的傅里叶耦合矩阵
- `E`是电场模式

**求解得到**：
- **传播常数** q_i（特征值）
- **模式场分布** φ_i（特征向量）

**模式场形式**：
```
E(x,y,z) = Σ_i [a_i exp(iq_i z) + b_i exp(-iq_i z)] φ_i(x,y)
```

其中：
- `a_i`: 前向传播模式振幅
- `b_i`: 后向传播模式振幅
- `q_i`: z方向传播常数

### 4. 层间连接：S矩阵方法

**问题**：如何连接不同层的模式？

**答案**：使用**S矩阵（散射矩阵）**或**T矩阵（传输矩阵）**

## S矩阵和T矩阵的区别

### 1. 基本定义

#### **T矩阵（传输矩阵，Transfer Matrix）**

T矩阵描述**输入-输出关系**：

```
[ a₀ ]   [ T₀₀  T₀₁ ] [ a₁ ]
[    ] = [          ] [    ]
[ b₀ ]   [ T₁₀  T₁₁ ] [ b₁ ]
```

**物理意义**：
- 输入：右侧的模式振幅 (a₁, b₁)
- 输出：左侧的模式振幅 (a₀, b₀)
- **方向**：从右到左（或从下到上）

**特点**：
- ✅ 适合级联多层结构
- ❌ 数值不稳定（当层很厚时，exp(iq·d)可能很大或很小）
- ❌ 不能直接处理边界条件

#### **S矩阵（散射矩阵，Scattering Matrix）**

S矩阵描述**散射关系**：

```
[ a₁ ]   [ S₀₀  S₀₁ ] [ a₀ ]
[    ] = [          ] [    ]
[ b₀ ]   [ S₁₀  S₁₁ ] [ b₁ ]
```

**物理意义**：
- `S₀₀`: 从左侧入射，左侧出射（反射）
- `S₀₁`: 从右侧入射，左侧出射（透射）
- `S₁₀`: 从左侧入射，右侧出射（透射）
- `S₁₁`: 从右侧入射，右侧出射（反射）

**特点**：
- ✅ 数值稳定（所有元素都是有界的）
- ✅ 物理意义清晰（直接对应反射/透射系数）
- ✅ 适合处理边界条件
- ✅ 可以级联（使用星积运算）

### 2. T矩阵到S矩阵的转换

**转换公式**（从代码`StarProduct.hpp`）：

```cpp
// T矩阵形式：
// [ a₀ ]   [ T₀₀  T₀₁ ] [ a₁ ]
// [    ] = [          ] [    ]
// [ b₀ ]   [ T₁₀  T₁₁ ] [ b₁ ]

// 转换为S矩阵：
// [ a₁ ]   [ S₀₀  S₀₁ ] [ a₀ ]
// [    ] = [          ] [    ]
// [ b₀ ]   [ S₁₀  S₁₁ ] [ b₁ ]

S₀₀ = inv(T₀₀)
S₀₁ = -inv(T₀₀) T₀₁
S₁₀ = T₁₀ inv(T₀₀)
S₁₁ = T₁₁ - T₁₀ inv(T₀₀) T₀₁
```

**推导过程**：

从T矩阵：
```
a₀ = T₀₀ a₁ + T₀₁ b₁
b₀ = T₁₀ a₁ + T₁₁ b₁
```

从第一个方程解出a₁：
```
a₁ = inv(T₀₀) a₀ - inv(T₀₀) T₀₁ b₁
```

代入第二个方程：
```
b₀ = T₁₀ [inv(T₀₀) a₀ - inv(T₀₀) T₀₁ b₁] + T₁₁ b₁
     = T₁₀ inv(T₀₀) a₀ + [T₁₁ - T₁₀ inv(T₀₀) T₀₁] b₁
```

因此：
```
S₀₀ = inv(T₀₀)
S₀₁ = -inv(T₀₀) T₀₁
S₁₀ = T₁₀ inv(T₀₀)
S₁₁ = T₁₁ - T₁₀ inv(T₀₀) T₀₁
```

### 3. S4中的实现

**代码位置**：`S4/rcwa.cpp` 中的 `GetSMatrix()` 函数

**关键步骤**：

1. **构建界面矩阵**（层l和层l+1之间的界面）：
```cpp
// 模式到场矩阵：
// M = [ B  -B ]  其中 B = kp*phi*inv(q)
//     [ A   A ]        A = phi

// 界面矩阵 = inv(M_l) * M_{l+1}
```

2. **转换为S矩阵**：
```cpp
// 从界面传输矩阵转换为界面S矩阵
// 代码在 rcwa.cpp 第1441-1447行
Copy(n2,n2, in1,n2, Saa,n4);
Invert(n2, Saa,n4, Sbb, n22, iwork);
Mult(n2,  1., in2,n2, Saa,n4, 0., Sba,n4);
Mult(n2, -1., Saa,n4, in2,n2, 0., Sab,n4);
Copy(n2,n2, in1,n2, Sbb,n4);
Mult(n2,  1., in2,n2, Sab,n4, 1., Sbb,n4);
```

3. **级联S矩阵**（星积运算）：
```cpp
// 使用StarProduct连接多层
// 代码在 StarProduct.hpp
```

**星积公式**（级联两个S矩阵）：
```
如果：
A: [a₁] = A [a₀]
          [b₁]     [b₀]

B: [a₂] = B [a₁]
          [b₁]     [b₂]

则级联结果C：
C₀₀ = B₀₀ inv(I - A₀₁ B₁₀) A₀₀
C₀₁ = B₀₀ inv(I - A₀₁ B₁₀) A₀₁ B₁₁ + B₀₁
C₁₀ = A₁₀ + A₁₁ inv(I - B₁₀ A₀₁) B₁₀ A₀₀
C₁₁ = A₁₁ inv(I - B₁₀ A₀₁) B₁₁
```

### 4. 为什么S4使用S矩阵？

**原因**：
1. **数值稳定性**：S矩阵元素有界，不会出现指数增长
2. **物理直观**：直接对应反射/透射系数
3. **边界条件**：容易处理入射和出射边界
4. **级联方便**：使用星积可以高效级联多层

**T矩阵的问题**：
- 当层很厚时，exp(iq·d)可能非常大或非常小
- 导致数值溢出或精度损失
- 需要特殊处理（如重新归一化）

## 衍射级次和角度计算

### 1. G矢量列表

**获取G矢量**：
```lua
G = S:GetGList()
-- G[i] = {m, n}  倒格矢坐标
```

**物理意义**：
- 每个G矢量对应一个平面波分量
- G = m·b₁ + n·b₂（倒格矢基）
- m, n是整数

### 2. 波矢计算

对于第i个G矢量（对应衍射级次(m,n)）：

**在倒格空间**：
```
G_x = m·b₁x + n·b₂x
G_y = m·b₁y + n·b₂y
```

**在实空间（考虑入射波矢）**：
```
k_x[i] = k_inc_x + G_x
k_y[i] = k_inc_y + G_y
```

**z方向传播常数**：
```
k_z[i] = sqrt(ω²ε - k_x[i]² - k_y[i]²)
```

**判断传播模式**：
- 如果 `k_x[i]² + k_y[i]² < ω²ε`：传播模式（k_z为实数）
- 否则：倏逝模式（k_z为虚数，指数衰减）

### 3. 衍射角计算

**极角θ**（与z轴的夹角）：
```
θ[i] = arcsin(sqrt(k_x[i]² + k_y[i]²) / (ω√ε))
```

**方位角φ**（在xy平面的方向）：
```
φ[i] = arctan2(k_y[i], k_x[i])
```

### 4. 代码实现

**获取衍射级次索引**（`S4/main_lua.c` 第2060-2090行）：
```c
static int S4L_Simulation_GetDiffractionOrder(lua_State *L){
    // ...
    n = Simulation_GetNumG(S, &G);
    for(i = 0; i < n; ++i){
        if(u == G[2*i+0] && v == G[2*i+1]){
            lua_pushinteger(L, i+1);
            return 1;
        }
    }
    return 0;
}
```

## 功率流和能量分布计算

### 1. 坡印廷矢量（Poynting Vector）

**定义**：
```
S = (1/2) Re(E × H*)
```

**z方向功率流**：
```
P_z = (1/2) Re(E_x H_y* - E_y H_x*)
```

### 2. S4中的实现

**代码位置**：`S4/S4.cpp` 第1975-2022行

**关键函数**：`GetZPoyntingFlux()`

**计算步骤**：

1. **获取模式振幅**：
```cpp
// ab包含前向和后向模式振幅
// ab[0:2n-1]: 前向振幅 a
// ab[2n:4n-1]: 后向振幅 b
```

2. **计算场分量**：
```cpp
// 从模式振幅计算电场和磁场
// E = kp * phi * inv(q) * a
// H = phi * a
```

3. **计算功率流**：
```cpp
// 前向功率流
forward = Σ_i Re(a_i * H_i*) / ω

// 后向功率流  
backward = Σ_i Re(b_i * H_i*) / ω
```

**详细实现**（`S4/rcwa.cpp` 第2200-2400行）：

```cpp
void GetZPoyntingFlux(
    size_t n,
    const double *kx, const double *ky,
    std::complex<double> omega,
    const std::complex<double> *q,
    // ...
    const std::complex<double> *ab,
    std::complex<double> *forw,  // 输出：前向功率流
    std::complex<double> *back,  // 输出：后向功率流
    std::complex<double> *work
){
    // 1. 计算电场和磁场分量
    // E = kp * phi * inv(q) * a
    // H = phi * a
    
    // 2. 计算每个模式的功率流
    for(size_t i = 0; i < n2; ++i){
        // 前向功率流
        forw[i] = conj(E[i]) * H[i] / omega;
        // 后向功率流
        back[i] = conj(E[i+n2]) * H[i+n2] / omega;
    }
}
```

### 3. 按衍射级次分解

**函数**：`GetPoyntingFluxByOrder()`

**输出**：每个衍射级次的功率流

**物理意义**：
- 每个衍射级次对应一个特定的传播方向
- 功率流分解显示能量在不同方向上的分布
- 可以计算每个衍射级次的透射/反射效率

### 4. 总功率流

**总前向功率流**：
```
P_forward = Σ_i |a_i|² * Re(q_i) / |q_i|
```

**总后向功率流**：
```
P_backward = Σ_i |b_i|² * Re(q_i) / |q_i|
```

**能量守恒**：
```
P_incident = P_forward + P_backward + P_absorbed
```

## 总结

### S4的输出流程

```
1. 输入：结构定义、频率、入射角
   ↓
2. 计算G矢量列表（倒格矢）
   ↓
3. 对每层：
   a. 计算介电常数傅里叶系数
   b. 求解特征值问题 → 得到传播模式
   c. 构建层内传输矩阵
   ↓
4. 层间连接：
   a. 构建界面矩阵
   b. 转换为S矩阵
   c. 级联S矩阵（星积）
   ↓
5. 应用边界条件：
   a. 入射边界：已知入射波
   b. 出射边界：无后向波
   c. 求解线性方程组 → 得到模式振幅
   ↓
6. 计算输出：
   a. 功率流（总功率）
   b. 按衍射级次分解的功率流
   c. 场分布（可选）
```

### S矩阵 vs T矩阵

| 特性 | S矩阵 | T矩阵 |
|------|-------|-------|
| **数值稳定性** | ✅ 稳定 | ❌ 不稳定（厚层） |
| **物理意义** | ✅ 直接对应反射/透射 | ⚠️ 需要转换 |
| **边界条件** | ✅ 容易处理 | ❌ 困难 |
| **级联** | ✅ 星积运算 | ✅ 矩阵乘法 |
| **S4使用** | ✅ **主要使用** | ⚠️ 仅内部转换 |

### 关键物理量

1. **G矢量**：倒格矢，定义衍射级次
2. **传播常数q**：z方向传播常数（特征值）
3. **模式φ**：场分布模式（特征向量）
4. **振幅a, b**：前向和后向模式振幅
5. **S矩阵**：连接不同层的散射关系
6. **功率流**：能量流动的方向和大小

### 衍射级次到角度的转换

```
G矢量 (m,n) 
  → k_x, k_y (波矢分量)
    → k_z (传播常数)
      → θ, φ (衍射角)
        → 功率流（能量分布）
```
