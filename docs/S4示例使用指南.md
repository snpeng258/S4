# S4示例使用指南

## 示例文件位置

所有示例都在 `examples/` 目录下，按类型分类：

```
examples/
├── 0d/          # 零维结构（非周期性）
├── 1d/          # 一维周期性结构
├── 2d/          # 二维周期性结构
├── simple/      # 最简单的入门示例 ⭐推荐从这里开始
├── patterns/    # 各种图案示例
├── MPI_example/ # MPI并行示例
└── ...
```

## 如何运行示例

### 方法1：使用已编译的S4程序

```bash
# 基本语法
.\build\S4.exe examples\路径\示例文件.lua

# 示例：运行简单示例
.\build\S4.exe examples\simple\simple.lua

# 示例：运行您当前查看的文件
.\build\S4.exe examples\1d\Christ_PRB_70_125113_2004\fig2b.lua

# 将输出保存到文件
.\build\S4.exe examples\simple\simple.lua > output.txt
```

### 方法2：交互式运行

```bash
# 启动交互式模式
.\build\S4.exe

# 然后在交互式环境中加载文件
dofile("examples/simple/simple.lua")
```

### 方法3：在脚本中传递参数

```bash
# 使用 -a 参数传递参数给脚本
.\build\S4.exe -a "0.6" examples\simple\simple.lua
# 脚本中可以通过 S4.arg 访问这个参数
```

## 理解示例代码结构

### 典型示例代码流程

所有S4示例都遵循相似的结构：

```lua
-- 1. 创建仿真对象
S = S4.NewSimulation()

-- 2. 设置晶格（周期性结构）
S:SetLattice({a1x, a1y}, {a2x, a2y})
S:SetNumG(数量)  -- 设置G矢量数量

-- 3. 定义材料
S:AddMaterial("材料名", {实部, 虚部})  -- 介电常数

-- 4. 添加层
S:AddLayer('层名', 厚度, '背景材料')

-- 5. 在层中设置图案（可选）
S:SetLayerPatternRectangle('层名', '材料', 中心, 角度, 半宽度)

-- 6. 设置激励（入射波）
S:SetExcitationPlanewave(
    {phi, theta},  -- 入射角度
    {s振幅, s相位}, -- s极化
    {p振幅, p相位}  -- p极化
)

-- 7. 设置频率
S:SetFrequency(频率)

-- 8. 计算和输出结果
结果 = S:GetPoyntingFlux('层名', z位置)
```

## 当前查看的示例详解

您正在查看的 `fig2b.lua` 是一个**金属光栅透射谱**的示例：

### 代码解析

```lua
-- 第6-8行：创建仿真，设置一维晶格，G矢量数量
S = S4.NewSimulation()
S:SetLattice({0.5,0}, {0,0})  -- 周期0.5的一维晶格
S:SetNumG(49)  -- 使用49个G矢量

-- 第9-12行：定义材料
S:AddMaterial("ITO", {2,0})      -- ITO（氧化铟锡）
S:AddMaterial("Quartz", {2.14,0}) -- 石英
S:AddMaterial("Vacuum", {1,0})   -- 真空
S:AddMaterial("Gold", {-5,0})    -- 金（初始值，后面会更新）

-- 第14-18行：定义层结构
S:AddLayer('Front', 0, 'Vacuum')           -- 前层（真空）
S:AddLayer('Grating', 0.015, 'Vacuum')     -- 光栅层，厚度0.015
S:SetLayerPatternRectangle('Grating', 'Gold', {0,0}, 0, {0.05,0})  -- 金矩形图案
S:AddLayer('Spacer', 0.015, 'ITO')         -- 间隔层
S:AddLayer('Back', 0, 'Quartz')            -- 后层（石英）

-- 第19行：获取金的真实材料（频率相关的介电常数）
Gold = S4.GetRealMaterial('Gold')

-- 第21-24行：设置平面波激励（p极化）
S:SetExcitationPlanewave(
    {0,0},  -- 垂直入射
    {0,0},  -- s极化振幅为0
    {1,0}   -- p极化振幅为1
)

-- 第26-27行：使用极化分解，设置分辨率
S:UsePolarizationDecomposition()
S:SetResolution(8)

-- 第31-35行：创建多个仿真副本用于并行计算
Sa = {S}
npar = 3
for i = 2,npar do
    Sa[i] = S:Clone()
end

-- 第37-54行：频率扫描循环
step = 0.002
for ev = 1.5,2.4,step*npar do  -- 能量范围1.5-2.4 eV
    for i = 1,npar do
        iev = ev+(i-1)*step
        f = 0.8065548889615557 * iev  -- 转换为频率
        l2 = 1/(f*f)  -- 波长平方
        
        -- 更新材料的频率相关介电常数
        Sa[i]:SetMaterial('Gold', {Gold:GetEpsilon(iev, 'eV')})
        Sa[i]:SetMaterial('ITO', {1 + 1.81302*l2/(l2-0.07597), 0})
        Sa[i]:SetFrequency(f)
    end
    
    -- 并行求解
    S4.SolveInParallel('Back', unpack(Sa))
    
    -- 输出结果（透射率）
    for i = 1,npar do
        iev = ev+(i-1)*step
        t = Sa[i]:GetPoyntingFlux('Back', 0)  -- 获取透射功率流
        print(iev, -math.log(t))  -- 输出能量和-log(透射率)
    end
    io.stdout:flush()
end
```

### 这个示例做什么？

1. **结构**：金属（金）光栅在ITO间隔层上，基底是石英
2. **计算**：扫描不同频率（能量），计算透射谱
3. **输出**：能量 vs -log(透射率) 的数据对
4. **优化**：使用并行计算加速频率扫描

## 如何修改示例

### 修改参数

```lua
-- 修改频率
S:SetFrequency(0.6)  -- 原来是0.5

-- 修改材料
S:AddMaterial("Silicon", {12,0})  -- 添加硅

-- 修改层厚度
S:AddLayer('Grating', 0.02, 'Vacuum')  -- 厚度从0.015改为0.02

-- 修改入射角度
S:SetExcitationPlanewave(
    {30,0},  -- 30度入射角
    {1,0},
    {0,0}
)
```

### 添加计算

```lua
-- 计算反射率
r = S:GetPoyntingFlux('Front', 0)

-- 计算透射率
t = S:GetPoyntingFlux('Back', 0)

-- 计算电场
E = S:GetEField({x, y, z})
print("电场:", E[1], E[2], E[3])

-- 计算磁场
H = S:GetHField({x, y, z})
```

### 频率扫描

```lua
-- 简单的频率扫描
for f = 0.4, 0.8, 0.01 do
    S:SetFrequency(f)
    t = S:GetPoyntingFlux('Back', 0)
    print(f, t)
end
```

## 常见输出结果

### 1. 透射/反射谱

```lua
-- 输出格式：频率 透射率
for f = 0.4, 0.8, 0.01 do
    S:SetFrequency(f)
    t = S:GetPoyntingFlux('Back', 0)
    print(f, t)
end
```

### 2. 场分布

```lua
-- 输出格式：位置 电场
for z = -1, 1, 0.1 do
    E = S:GetEField({0, 0, z})
    print(z, E[1], E[2], E[3])
end
```

### 3. 功率流

```lua
-- 输出前向和后向功率流
forward, backward = S:GetPowerFlux('LayerName', z)
print("前向:", forward, "后向:", backward)
```

## 调试技巧

### 1. 检查结构

```lua
-- 输出层描述
S:OutputLayerDescription('LayerName')

-- 输出图案实现（可视化）
S:OutputLayerPatternRealization('LayerName', 128, 128)
```

### 2. 设置详细输出

```lua
-- 在脚本开头设置详细度
S4.verbosity = 1  -- 0=静默, 1=正常, 2=详细
```

### 3. 检查材料

```lua
-- 获取材料信息
mat = S4.GetRealMaterial('Gold')
eps = mat:GetEpsilon(1.5, 'eV')  -- 在1.5eV时的介电常数
print("介电常数:", eps)
```

## 常见问题

### Q: 如何知道示例需要什么参数？
A: 查看示例开头的注释，通常有说明。也可以查看S4的API文档。

### Q: 如何修改示例以适应我的结构？
A: 
1. 复制示例文件
2. 修改材料定义
3. 修改层结构
4. 调整计算部分

### Q: 示例运行很慢怎么办？
A: 
- 减少 `SetNumG()` 的值（但可能影响精度）
- 使用并行计算（如您查看的示例）
- 减少频率扫描的步数

### Q: 如何可视化结果？
A: 
- 将输出保存到文件：`S4.exe script.lua > output.txt`
- 使用Python/Matlab读取数据并绘图
- 使用 `OutputLayerPatternRealization()` 输出结构图像
