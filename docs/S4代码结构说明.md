# S4代码结构说明

## 项目概述

**S4 (Stanford Stratified Structure Solver)** 是一个用于计算周期性分层结构中电磁场的程序，由斯坦福大学电气工程系Fan小组的Victor Liu开发。

S4使用**RCWA (Rigorous Coupled-Wave Analysis, 严格耦合波分析)** 和 **FMM (Fourier Modal Method, 傅里叶模态方法)** 来求解周期性分层结构的电磁场问题。

## 整体架构

S4项目包含以下几个主要部分：

1. **核心库 (Core Library)** - C/C++实现的计算引擎
2. **Lua前端** - 通过Lua脚本接口使用S4
3. **Python扩展** - Python绑定
4. **C API** - 底层C接口
5. **示例和文档** - 使用示例和文档

## 核心模块详解

### 1. S4核心库 (`S4/`)

#### 1.1 主入口 (`main_lua.c`)
- **功能**: Lua解释器的主程序入口
- **关键函数**:
  - `main()`: 程序入口，解析命令行参数，初始化Lua状态
  - `luaopen_RCWA()`: 注册S4的Lua API函数
  - `new_S4_lua_state()`: 创建新的Lua状态并加载S4模块

#### 1.2 核心仿真引擎 (`S4.cpp`, `S4.h`)
- **功能**: 提供S4仿真的核心数据结构`S4_Simulation`和主要API
- **关键结构**:
  ```c
  typedef struct S4_Simulation_ S4_Simulation;
  ```
- **主要功能**:
  - 材料定义和管理
  - 层结构定义
  - 几何图案设置（圆形、椭圆、矩形、多边形）
  - 频率和波矢设置
  - 场计算和功率流计算

#### 1.3 RCWA算法 (`rcwa.cpp`, `rcwa.h`)
- **功能**: 实现严格耦合波分析(RCWA)算法
- **关键函数**:
  - `SolveInterior()`: 求解层内场分布
  - `GetSMatrix()`: 计算S矩阵（散射矩阵）
  - `GetLayerZIntegral()`: 计算层内z方向积分
- **算法特点**:
  - 使用S矩阵方法连接多层结构
  - 支持前向和后向传播模式
  - 处理周期性边界条件

#### 1.4 FMM模块 (`S4/fmm/`)
FMM (Fourier Modal Method) 是S4的核心算法之一，包含多个实现：

- **`fmm_common.cpp`**: FMM通用功能
- **`fmm_FFT.cpp`**: 基于FFT的FMM实现
- **`fmm_kottke.cpp`**: Kottke方法的FMM实现
- **`fmm_closed.cpp`**: 闭合形式FMM
- **`fmm_PolBasisNV.cpp`**: 归一化向量极化基
- **`fmm_PolBasisVL.cpp`**: 向量场极化基
- **`fmm_PolBasisJones.cpp`**: Jones向量极化基
- **`fmm_experimental.cpp`**: 实验性FMM实现

#### 1.5 几何图案处理 (`S4/pattern/`)
- **`pattern.c/h`**: 图案定义和处理
- **`intersection.c/h`**: 几何相交计算
- **`predicates.c`**: 几何谓词（用于精确几何计算）

#### 1.6 数值计算库 (`S4/RNP/`)
RNP (可能是"RNP Numerical Package"的缩写) 提供：
- **`Eigensystems.*`**: 特征值系统求解
- **`LinearSolve.*`**: 线性方程组求解
- **`TBLAS.*`**: 模板化BLAS操作

#### 1.7 FFT库 (`S4/kiss_fft/`)
- 使用Kiss FFT库进行快速傅里叶变换
- 支持多维FFT

### 2. S4r重构版本 (`S4r/`)

S4r是S4的C++重构版本，采用更现代的面向对象设计：

#### 2.1 仿真类 (`Simulation.hpp/cpp`)
```cpp
struct Simulation {
    PeriodicMesh *mesh;
    MaterialList materials;
    LayerList layers;
    doublecomplex omega;  // 频率
    // 激励设置
    // 求解方法
};
```
- **功能**: 管理整个仿真过程
- **主要方法**:
  - `SetMaterial()`: 设置材料
  - `AddLayer()`: 添加层
  - `SetRegionCircle/Rectangle/Polygon()`: 设置区域形状
  - `SolveAllLayers()`: 求解所有层
  - `GetFields()`: 获取场分布
  - `GetPowerFlux()`: 获取功率流

#### 2.2 材料类 (`Material.hpp/cpp`)
- 定义材料的介电常数、磁导率等属性
- 支持各向同性和各向异性材料

#### 2.3 层类 (`Layer.hpp/cpp`)
- 定义层的厚度、材料组成
- 管理层内的几何图案

#### 2.4 周期性网格 (`PeriodicMesh.hpp/cpp`)
- 处理周期性结构的网格划分
- 管理倒格矢和G矢量

#### 2.5 形状类 (`Shape.hpp/cpp`)
- 定义各种几何形状（圆形、椭圆、矩形、多边形）

## 工作流程

### 典型使用流程

1. **初始化仿真**
   - 创建`S4_Simulation`对象
   - 设置晶格参数（周期性）

2. **定义材料**
   - 添加材料（介电常数、磁导率等）

3. **定义层结构**
   - 添加层并设置厚度
   - 在层内设置几何图案（圆形、矩形等）

4. **设置激励**
   - 设置频率（omega）
   - 设置入射波矢（k）
   - 设置极化方向

5. **求解**
   - 调用求解函数
   - 计算各层的模式
   - 通过S矩阵连接各层

6. **后处理**
   - 计算透射/反射
   - 计算场分布
   - 计算功率流

### 算法流程

```
输入: 结构定义、频率、波矢
  ↓
1. 计算倒格矢和G矢量列表
  ↓
2. 对每一层:
   a. 计算介电常数的傅里叶级数
   b. 构建FMM矩阵
   c. 求解特征值问题（得到传播常数q和模式）
  ↓
3. 构建S矩阵连接各层
  ↓
4. 应用边界条件（入射和出射）
  ↓
5. 求解线性方程组得到各层模式系数
  ↓
6. 计算输出量（透射、反射、场分布等）
```

## 关键算法

### RCWA (严格耦合波分析)
- 将周期性结构展开为傅里叶级数
- 在倒格空间求解麦克斯韦方程组
- 使用S矩阵方法连接多层

### FMM (傅里叶模态方法)
- 将介电函数展开为傅里叶级数
- 在倒格空间构建耦合矩阵
- 求解特征值问题得到传播模式

### S矩阵方法
- 每层有输入和输出端口
- S矩阵描述层间的散射关系
- 通过级联S矩阵得到整体响应

## 接口说明

### Lua API
S4主要通过Lua脚本使用，主要API包括：
- `S4.NewSimulation()`: 创建新仿真
- `S4.SetMaterial()`: 设置材料
- `S4.AddLayer()`: 添加层
- `S4.SetRegionCircle()`: 设置圆形区域
- `S4.SetFrequency()`: 设置频率
- `S4.GetPowerFlux()`: 获取功率流
- `S4.GetFields()`: 获取场分布

### C API
底层C API定义在`S4.h`中，包括：
- `S4_Simulation_New()`: 创建仿真对象
- `S4_Simulation_SetMaterial()`: 设置材料
- `S4_Simulation_AddLayer()`: 添加层
- `S4_Simulation_Solve()`: 求解
- `S4_Simulation_GetPowerFlux()`: 获取功率流

## 依赖库

1. **Lua**: 脚本语言解释器
2. **Eigen**: 线性代数库（可选，S4r使用）
3. **LAPACK/BLAS**: 线性代数库（可选）
4. **MPI**: 并行计算支持（可选）
5. **Kiss FFT**: FFT库（内置）

## 扩展模块

### 函数采样器 (`modules/`)
- `FunctionSampler1D`: 一维函数采样
- `FunctionSampler2D`: 二维函数采样

### 外部接口 (`ext/`)
- **MATLAB接口**: 通过MEX文件调用S4
- **R接口**: R语言绑定

## 示例代码

示例代码位于`examples/`目录，按类型分类：
- **0d/**: 零维结构（非周期性）
- **1d/**: 一维周期性结构
- **2d/**: 二维周期性结构
- **MPI_example/**: MPI并行示例
- **patterns/**: 各种图案示例

## 总结

S4是一个功能完整的周期性结构电磁仿真工具，其代码结构清晰：

1. **核心计算**: `S4/`目录包含RCWA和FMM算法实现
2. **现代接口**: `S4r/`提供C++面向对象接口
3. **脚本接口**: 通过Lua提供易用的脚本接口
4. **扩展性**: 支持Python、MATLAB、R等接口
5. **并行支持**: 支持MPI和线程并行

代码采用模块化设计，核心算法（RCWA、FMM）与接口层分离，便于维护和扩展。
