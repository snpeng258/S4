## 1. 当前研究主线

**已确定：**研究对象是周期性光栅，周期不是固定先验。可见光验证样品的候选周期为 1200-1500 nm，EUV 样品周期将随波长尺度缩小。研究拟通过多波长、变入射角和变方位角的散射测量增加独立观测信息，再结合电磁正演与参数反演，降低光栅结构参数之间的耦合。

当前可以把研究主线概括为：

> 先用 375 nm、405 nm、445 nm 三波段搭建和验证可见光散射测量原理，再迁移到由 800 nm 基波产生的第 55-61 次高次谐波，即约 14.55-13.11 nm 的 EUV 波段；在有限相机靶面、有限光斑和可收集衍射级次的约束下，联合设计波长、入射角、方位角和衍射级次，以提升周期光栅几何参数的可辨识性。

这里的“提升可辨识性”需要和“衍射光能被相机接收到”严格区分：前者是反演问题，后者是仪器几何问题。当前 MATLAB 代码主要解决后者。

## 2. 两阶段验证逻辑

### 2.1 可见光原理验证

**已确定：**

- 波长：375 nm、405 nm、445 nm。
- 样品：周期性光栅。
- 候选周期范围：1200-1500 nm，不作为固定已知量。
- 计划通过旋转入射角增强结构参数解耦。
- 入射角定义为相对样品法线的夹角。
- 方位角定义为光栅周期方向与入射光在样品面内投影方向的夹角。
- 两台用于衍射级次收集的相机保持固定，分别收集 +1 级和 -1 级；通过样品旋转改变测量方位角。
- 0 级光由专门的光斑分析仪接收；高于一级的衍射级次在小线宽、大入射角条件下难以收集，暂不作为主要观测量。
- 当前观测量是不同波长、角度和衍射级次下分开记录的强度，尚未组合成级次比值。

**代码现状：**

- 光栅周期当前设为 1200 nm，后续需纳入 1200-1500 nm 范围。
- 入射角固定为 55°。
- 方位角在 0°-180°内取 91 个点，即 2°步长。
- 计算 0、+1、-1 三个衍射级次的传播方向。
- 分别设置 0 级相机、+1 级相机 A、-1 级相机 B。

**待确认：**可见光阶段究竟验证以下哪些内容：

1. 只验证光路、旋转机构和衍射级次捕获；
2. 同时验证衍射强度测量的重复性和归一化；
3. 进一步完成光栅轮廓参数反演，并证明角度变化确实降低参数相关性。

这三种目标对应不同的实验闭环，不能混为“原理验证”。

### 2.2 EUV 检测阶段

**已确定：**

- 基波：800 nm。
- HHG 级次：第 55-61 次。
- 对应波长：约 14.55-13.11 nm。
- 光栅周期将相对可见光样品同步缩小，但具体缩放规则尚未固定。
- 目标是将可见光阶段形成的测量和解耦方法迁移到 EUV 周期光栅检测。

**当前假设：**可见光阶段主要验证几何、控制、数据处理和反演框架；EUV 阶段需要重新进行级次可达性、探测器覆盖、材料光学常数、真空传播、通量和信噪比设计，不能直接复用可见光相机布局。如果“同步缩小”指保持相近的 `lambda/pitch`，则 EUV 周期大致会落在 35-58 nm；这只是由当前波长与周期范围推得的候选区间，尚未由用户确认。

## 3. 当前代码所表达的仪器几何

### 3.1 已实现的几何模型

脚本使用归一化切向波矢描述二维光栅衍射：入射波的切向分量与方位角方向上的光栅矢量相加或相减，得到正负一级衍射的切向分量；当其平方和不超过 1 时，认为该级次可传播，并由正的法向分量得到反射侧传播方向。

当前参数如下：

| 参数 | 当前值 | 含义 |
|---|---:|---|
| `P.lambdas` | 375/405/445 nm | 可见光三波段 |
| `P.pitch` | 1200 nm | 当前代码值；实验候选范围为 1200-1500 nm |
| `P.theta_i` | 55° | 固定入射角；从代码坐标看是相对样品法线的角度 |
| `P.phi` | 90° | 初始方位角 |
| `P.L0` | 200 mm | 0 级相机靶面距离 |
| `P.LA` | 220 mm | +1 级相机 A 靶面距离 |
| `P.LB` | 250 mm | -1 级相机 B 靶面距离 |
| `P.spot_radius` | 1.5 mm | 靶面光斑半径 |
| 0 级传感器 | 11 mm x 11 mm | 0 级探测区域 |
| A/B 传感器 | 37 mm x 37 mm | 正负一级探测区域 |

用户确认两台衍射级次相机固定。当前代码同时还定义了一个独立的 0 级相机，因此实验系统究竟是“两台相机兼顾 0/±级次”还是“0 级另有探测通道”，仍需与实际光路统一。

### 3.2 相机寻优逻辑

相机 A 先以方位角 90°为锚点，要求三个可见波长的 +1 级光斑及其外沿都落入 37 mm x 37 mm 靶面；在满足锚点硬约束的候选姿态中，最大化其对全部 3 x 91 个“波长-方位角”组合的覆盖。

相机 B 随后针对相机 A 没有覆盖的组合进行增量寻优，但它接收的是 -1 级衍射。最终得分是 A 的覆盖数与 B 对 A 盲区的补充数之和。

因此，这段代码当前回答的是：

> 在入射角固定为 55°时，如何布置固定方向、独立距离的相机，使 375/405/445 nm 的正负一级衍射在方位角扫描过程中尽量多地落在传感器上？

它还没有回答：

> 哪些入射角和方位角组合对光栅高度、线宽、侧壁角等参数具有互补灵敏度，并能降低反演相关性？

### 3.3 需要在后续版本处理的代码边界

1. **入射角尚未扫描。** `theta_i` 固定为 55°，当前滑块扫描的是方位角 `phi`。
2. **只计算 0、+1、-1 级。** EUV 下的波长/周期比与可见光不同，可能存在更多可传播级次，需要重新枚举，而不能直接套用当前三级次模型。
3. **覆盖得分与光斑外沿约束不完全一致。** 相机 A 的 90°锚点使用了 1.5 mm 光斑半径，但全局覆盖计分和相机 B 计分只检查光斑中心是否落入传感器。
4. **代码只判断几何可达性。** 尚未计算各级衍射效率、探测器动态范围、噪声、曝光时间或弱级次是否具有实际可测性。
5. **尚未建立参数解耦指标。** 没有计算 RCWA 响应对结构参数的 Jacobian、灵敏度矩阵、条件数、Fisher 信息矩阵、协方差或参数相关系数。
6. **相机实体外形只用于绘图。** 当前寻优没有检查相机外壳之间、相机与入射光路之间的机械碰撞或遮挡。
7. **MATLAB 文件名与主函数名不一致。** 文件名是 `Scatterometry_Single_Anchor_SpotSize.m`，主函数名是 `Scatterometry_Asymmetric_Independent_Distances`；按 MATLAB 常规调用规则应统一，否则可能无法直接按函数名调用。

## 4. 建议采用的研究逻辑，而不是笼统时间线

### 4.1 定义待测量和待反演对象

**已确定：**高度与槽深指同一个垂直尺寸；CD 是待反演参数，定义为顶部 CD；左右侧壁角分别反演。当前参数向量暂定为

`p = {周期 Λ，高度/槽深 h，顶部 CD，左侧壁角 α_L，右侧壁角 α_R}`。

底部 CD 和截面随高度的横向变化由 `h`、顶部 CD 及两个侧壁角共同确定，不再作为独立参数。侧壁角相对样品表面还是样品法线定义仍需与 RCWA 代码统一。正负一级组合量的简短备忘见[可探索方向.md](可探索方向.md)。

### 4.2 建立统一正演链

将研究拆成连续的正演链：

`波长/偏振/入射角/方位角 -> RCWA 衍射效率 -> 衍射方向 -> 相机靶面位置与有效信号`

当前代码已经覆盖“衍射方向 -> 靶面位置”的主要几何部分，尚需与 RCWA 的级次效率输出接起来。

### 4.3 定义可辨识性与解耦指标

对每个候选测量条件计算结构参数灵敏度。不能只以“收集到的点最多”为最优目标，而应同时考虑：

- 有效可测级次数量；
- 各级次信号强度与噪声；
- 不同结构参数的响应方向是否相似；
- 灵敏度矩阵是否病态；
- 加入新角度或新波长后，参数协方差是否下降。

### 4.4 联合设计波长、入射角、方位角和相机布局

几何覆盖优化负责排除“接收不到”的方案，可辨识性优化负责从可行方案中选出“对参数最有信息”的测量组合。两层优化应串联，而不是用覆盖率代替解耦能力。

### 4.5 完成从可见光到 EUV 的迁移验证

可见光阶段用于建立可重复的测量、标定、归一化和反演闭环。EUV 阶段重新代入 HHG 波长、EUV 材料光学常数、实际通量、探测器和真空几何，并验证可见光阶段得到的角度设计原则哪些仍成立、哪些需要重构。

## 5. Corazza 等 2026 年论文与当前解耦思路

已核验论文：Corazza et al. (2026), *Broadband extreme ultraviolet zeroth order scatterometry for nanostructure metrology*, Nature Communications, DOI `10.1038/s41467-026-73052-w`。用户给出的附件 key `B5PUIGEM` 是该工作的 2025 年 Research Square 预印本；研究文档引用正式发表版本。

### 5.1 论文实际采用的解耦方法

论文把参数简化为 `p = {CD, GH}`，其中周期已知、侧壁角通过制程设计尽量减小。它利用两个方位角下零级光谱的灵敏度方向差异：

- `phi = 90°` 为锥形衍射条件，光栅线与入射面平行，阴影效应消失；零级相对反射率主要由槽深产生的相位积累决定，对 CD 较不敏感。
- `phi = 0°` 为平面衍射条件，大入射角下相邻光栅线产生部分阴影，零级光谱同时依赖 CD 和槽深。
- 反演并非在一个损失函数中人为提高 90°数据的权重，而是先用 90°数据反演槽深，再把槽深作为先验带入 0°数据反演 CD。
- 加权最小二乘中的权重取自测量方差的倒数，目的是反映噪声可信度，而不是人为强调某个结构参数。

### 5.2 对当前研究的可推广部分

用户的思路可以理解为把论文的“两方位角、零级、两参数”方案扩展成“多方位角、多入射角、零级加正负级次、多参数”方案。建议把信息通道暂时分为：

1. **衍射位置通道**：光斑角位置首先约束周期和角度零偏。周期不宜完全依赖强度反演，因为衍射方向对周期有更直接的几何编码。
2. **90°零级通道**：作为槽深/垂直尺寸的高灵敏度通道，先形成槽深先验。
3. **非 90°零级通道**：同时包含槽深、CD 和侧壁几何的混合编码，在槽深已有先验后用于横向参数估计。
4. **正负衍射级次通道**：用于补充横向轮廓和侧壁形状信息，并检验零级反演结果。
5. **联合精修**：最后用全部强度数据进行一次联合反演，输出协方差和参数相关系数，而不是停在逐通道结果。

### 5.3 关于正负级次和侧壁角的关键判断

收集正负级次很有价值，但“正负级次天然解耦侧壁角”目前仍是待验证假设。对于左右对称、只有一个公共侧壁角的梯形光栅，`+m` 与 `-m` 在对称测量条件下可能提供近似重复的信息；侧壁角更可能编码在多个级次之间的强度重新分配，以及其随波长、入射角和方位角的变化中。

如果左右侧壁角不同，或者非对称入射破坏了镜像对称性，`I(+m)-I(-m)` 才可能成为更直接的非对称性通道。因此后续应分别考察：

- 对称信息：`I(+m)+I(-m)` 或各级次归一化强度；
- 非对称信息：`[I(+m)-I(-m)]/[I(+m)+I(-m)]`；
- 各信息量对槽深、CD、周期和侧壁角的 Jacobian 是否线性独立。

### 5.4 对“给 90°更大深度权重”的修正表达

建议不要先人为设定一个更大的经验权重。更稳健的实现有三种：

1. 按论文做分阶段反演：90°估计槽深，再把槽深及其不确定度作为先验传给其他方位角。
2. 在联合损失函数中仍使用测量方差权重，同时通过先验协方差体现槽深通道的可信度。
3. 用 Fisher 信息矩阵或 Jacobian 条件数选择测量角度，让数据本身提供解耦能力，而不是通过损失函数强行制造。

## 6. 当前研究问题草案

以下内容只是为了承接讨论，尚未进入正式研究提案大纲。

**核心问题草案：**

> 在有限光斑、有限探测器面积和可测衍射效率的工程约束下，如何联合选择多波长、入射角、方位角和衍射级次，使周期性光栅多个轮廓参数的反演相关性降低，并形成一套可从可见光验证迁移到 HHG-EUV 检测的散射测量方法？

**可能的子问题：**

1. 哪些结构参数是当前系统真正要区分的，哪些参数可由先验值固定？
2. 入射角变化和方位角变化分别为哪些参数提供新的独立信息？
3. 多波长和多级次对参数灵敏度与相关性的贡献能否定量分离？
4. 以几何覆盖率为目标得到的相机布局，是否与以反演不确定度为目标得到的布局一致？
5. 可见光验证得到的实验设计原则在 EUV 波段迁移时受哪些物理和工程因素限制？

## 7. 已确认信息与下一轮问题

### 已确认：几何参数化

高度与槽深为同一尺寸；CD 取顶部 CD；左右侧壁角分别反演。底部 CD 由上述参数计算。

### 已确认：两台固定相机与零级通道

两台固定相机只负责 +1 和 -1 级，0 级由专门的光斑分析仪接收。其他级次因小线宽、大入射角下收集困难，当前不纳入主要方案。

### 问题 C：当前 RCWA 仿真的数据结构

当前仿真已经输出分开的级次强度。下一步需要确认数据是否包含 `I(lambda, theta, phi, m)` 的完整四维扫描，以及是否已经加入噪声、光源功率变化和探测器响应。若已有一份代表性输出，可据此直接构造 Jacobian 和参数相关性测试。
