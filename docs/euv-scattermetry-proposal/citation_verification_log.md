## 初步证据主题（待用户确认后进入研究提案大纲）

1. EUV 散射计量的核心优势不是单一的“波长更短”，而是较大入射角下的小测量光斑、非零级衍射信息、材料/薄层敏感性，以及对周期三维结构的非破坏测量能力。
2. 台式 HHG、紧凑等离子体源与多波长方案已证明可行，但从原型到近线/在线工具仍受通量、探测器速度、目标定位、稳定性、标定和吞吐量约束。
3. 重建精度常由模型误差而非纯测量噪声主导，尤其涉及材料光学常数、界面/覆盖层、粗糙度、污染、有限光束、样品倾斜和结构参数化。
4. 复杂三维结构引入参数相关、多局部极小值与解不唯一；多波长、多角度、多偏振、相位信息及散射/荧光混合计量可增加独立信息并降低歧义。
5. 文献中的高精度结果需要区分真实实验与合成数据，并通过 CD-SAXS、TEM、AFM 或商业工具做交叉验证，不能只用正演模型自洽作为准确性证明。
