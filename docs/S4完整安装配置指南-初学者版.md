# S4完整安装配置指南（Windows初学者版）

## 📋 当前状态检查

根据检查，您的电脑目前**还没有安装**运行S4所需的工具：
- ❌ GCC编译器（用于编译C/C++代码）
- ❌ Lua解释器（S4使用Lua脚本）
- ❌ Make工具（用于自动化编译）
- ❌ 已编译的S4程序

## 🎯 安装方案选择

### 方案A：使用MSYS2（推荐⭐）

**优点**：
- 安装简单，一键安装所有工具
- 适合Windows系统
- 官方推荐方式

**缺点**：
- 需要下载约500MB的安装包
- 首次安装需要10-20分钟

### 方案B：使用WSL（Windows子系统）

**优点**：
- 完整的Linux环境
- 适合熟悉Linux的用户

**缺点**：
- 需要安装WSL（如果还没安装）
- 对初学者可能较复杂

**本指南将重点介绍方案A（MSYS2）**，因为它最简单！

---

## 📦 第一步：下载并安装MSYS2

### 步骤1.1：下载MSYS2

1. 打开浏览器，访问：**https://www.msys2.org/**
2. 点击页面上的 **"Download the installer"** 按钮
3. 下载文件（文件名类似：`msys2-x86_64-latest.exe`，约500MB）

### 步骤1.2：安装MSYS2

1. **双击**下载的安装文件
2. 如果出现"用户账户控制"提示，点击 **"是"**
3. 安装向导会出现，点击 **"下一步"**
4. **选择安装位置**（建议使用默认位置：`C:\msys64`）
   - 如果C盘空间不足，可以选择其他盘（如：`D:\msys64`）
   - **记住这个路径，后面会用到！**
5. 点击 **"下一步"**，然后点击 **"安装"**
6. 等待安装完成（可能需要5-10分钟）
7. 安装完成后，**不要立即关闭**，点击 **"立即运行MSYS2"** 或 **"完成"**

### 步骤1.3：首次启动MSYS2

1. 安装完成后会自动打开一个**黑色终端窗口**（MSYS2终端）
2. 如果没自动打开，可以在开始菜单搜索 **"MSYS2 MSYS"** 并打开
3. 终端会自动运行一些初始化命令，**等待它完成**（可能需要1-2分钟）

---

## 🔧 第二步：在MSYS2中安装编译工具

### 步骤2.1：更新MSYS2（重要！）

在MSYS2终端窗口中，**复制并粘贴**以下命令，然后按**回车键**：

```bash
pacman -Syu
```

**说明**：
- 这会更新MSYS2的软件包管理器
- 可能会提示"是否继续？"，输入 `Y` 然后按回车
- 更新完成后，**可能会提示需要关闭终端重新打开**，请按照提示操作

### 步骤2.2：重新打开MSYS2终端

如果提示需要重新打开：
1. 关闭当前的MSYS2终端窗口
2. 在开始菜单搜索 **"MSYS2 MSYS"** 并重新打开

### 步骤2.3：安装GCC编译器

在MSYS2终端中，**复制并粘贴**以下命令，然后按回车：

```bash
pacman -S mingw-w64-x86_64-gcc
```

- 提示是否继续时，输入 `Y` 然后按回车
- 等待安装完成（可能需要2-5分钟）

### 步骤2.4：安装G++编译器（C++编译器）

```bash
pacman -S mingw-w64-x86_64-g++
```

- 提示是否继续时，输入 `Y` 然后按回车

### 步骤2.5：安装Make工具

```bash
pacman -S mingw-w64-x86_64-make
```

- 提示是否继续时，输入 `Y` 然后按回车

### 步骤2.6：安装Lua解释器

```bash
pacman -S mingw-w64-x86_64-lua
```

- 提示是否继续时，输入 `Y` 然后按回车

### 步骤2.7：安装数学库（BLAS和LAPACK）

```bash
pacman -S mingw-w64-x86_64-openblas
pacman -S mingw-w64-x86_64-lapack
```

- 每个命令提示时都输入 `Y` 然后按回车

## ⚙️ 第三步：配置环境变量（让Windows能找到这些工具）

### 方法1：临时配置（当前会话有效）

**在Cursor的终端中**（不是MSYS2终端），运行：

```powershell
$env:Path += ";C:\msys64\mingw64\bin"
```

**注意**：如果您的MSYS2安装在其他位置（比如D盘），请修改路径：
- 如果安装在 `D:\msys64`，则使用：`$env:Path += ";D:\msys64\mingw64\bin"`

### 方法2：永久配置（推荐⭐）

1. 按 **Win键 + R**，输入 `sysdm.cpl`，按回车
2. 点击 **"高级"** 选项卡
3. 点击 **"环境变量"** 按钮
4. 在 **"用户变量"** 区域，找到 **"Path"** 变量，点击 **"编辑"**
5. 点击 **"新建"** 按钮
6. 输入：`C:\msys64\mingw64\bin`
   - 如果您的MSYS2安装在其他位置，请修改为实际路径
7. 点击 **"确定"** 保存所有窗口
8. **重要**：关闭并重新打开Cursor，让环境变量生效

## ✅ 第四步：验证安装

在Cursor的终端中（重新打开后），运行以下命令检查：

```powershell
# 检查GCC
gcc --version

# 检查G++
g++ --version

# 检查Make
make --version

# 检查Lua
lua -v
```

**如果每个命令都能显示版本信息，说明安装成功！** ✅

如果某个命令显示"找不到"或"无法识别"，请：
1. 确认环境变量已正确配置
2. 确认已重新打开Cursor
3. 检查MSYS2的安装路径是否正确

## 📝 常见问题解答

### Q1: MSYS2安装很慢怎么办？

**A**: 
- 检查网络连接
- 尝试使用国内镜像（如果可用）
- 耐心等待，首次安装确实需要一些时间

### Q2: 编译时出现错误怎么办？

**A**: 
- 检查是否所有工具都已正确安装（运行第四步的验证命令）
- 确认环境变量已配置
- 尝试清理后重新编译：
  ```powershell
  make clean
  make
  ```

### Q3: 找不到S4.exe文件？

**A**: 
- 确认编译过程没有错误
- 检查 `build` 目录是否存在：
  ```powershell
  dir build
  ```
- 如果build目录不存在，说明编译可能失败了

### Q4: 运行S4时提示找不到DLL？

**A**: 
- 确认环境变量已正确配置（第三步）
- 尝试在MSYS2终端中运行：
  ```bash
  cd /path/to/S4程序包/upstream
  ./build/S4 examples/simple/simple.lua
  ```

### Q5: 如何更新S4？

**A**: 
- 如果代码有更新，只需重新编译：
  ```powershell
  cd "C:\Users\PSN\Desktop\s4-github\S4"
  make clean
  make
  ```
